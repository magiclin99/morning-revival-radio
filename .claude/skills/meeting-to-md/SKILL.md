# 特會晨興聖言 → Markdown

輸入一個特會網頁，產出一份逐字忠於原文、綱要編號完整的 `.md`。

**用讀的，不寫轉換程式。** 工具只拿來抓網頁和檢視結構；層級判斷、經節辨識、排版都由你讀懂內容後直接用 Write 寫出來。網頁編輯者常有不規則的寫法，硬寫規則一定會漏（見下方「已知的坑」）。

---

## 步驟

### 1. 抓網頁原始 HTML

```bash
mkdir -p <scratchpad>/web
curl -sL -A "Mozilla/5.0" "<URL>" -o <scratchpad>/web/page.html
```

- Wix 網站是伺服器端渲染，`curl` 就拿得到完整內容。
- **不要用 WebFetch**：它會摘要、截斷。
- **不要拿網頁轉出的 PDF 或 txt 當來源**：綱要第三層以下的編號在那裡已經掉了。

### 2. 看出區塊結構

只去標籤、保留區塊種類，印出來自己讀。正文從 `<h2>`（特會名稱）開始，到最後一段「參讀：…」結束；頁首導覽列和頁尾的聯絡資訊都不要。

```bash
python3 -I - <scratchpad>/web/page.html <<'EOF'
import sys, re, html
h = open(sys.argv[1], encoding='utf-8').read()
s = h.rfind('<h2', 0, h.find('訓練')); e = h.find('</div>', h.rfind('參讀'))
for m in re.finditer(r'<(h2|p|ol|ul|/ol|/ul)\b[^>]*>(.*?)(?=<(?:h2|p|ol|ul|/ol|/ul)\b|$)', h[s:e], re.S):
    tag, body = m.group(1), m.group(2)
    t = html.unescape(re.sub('<[^>]+>', '', body)).replace('​', '').replace('\xa0', ' ').strip()
    if tag in ('ol', 'ul', '/ol', '/ul'): print(f'[{tag}]')
    elif t: print(f'{tag}: {t}')
EOF
```

輸出很長時分段讀，但每一段都要讀到。

### 3. 照下方格式寫 `.md`

用 Write 一次寫出整份檔案。檔名用使用者指定的；沒指定就用 `{西元年}_{特會縮寫}.md`，例如國際長老及負責弟兄訓練是 `2026_ITERO.md`。不知道縮寫就問。

### 4. 驗證（必做）

1. **逐字比對**：兩邊都只留中日韓文字，用 difflib 比。差異只能是你自己加的標題（總題、綱要、晨興聖言）和你拿掉的「第一週•」字樣。其他任何差異都要回頭修。
2. **派一個 Haiku 子代理獨立核對**：給它 .md 路徑、`page.html` 路徑，以及「哪些改動是刻意的」清單，請它只讀不改。
3. **子代理的報告要自己再查一次**：它可能算錯數量（例如說每天都有 2 處經節，其實有一天只有 1 處）。

## 已知的坑

### 坑 1：綱要的列表被 Wix 攤平

網頁上綱要分成五層，但 HTML 裡只有前兩層寫在文字裡，第三層以下是**同一層、彼此相鄰**的 `<ol>`／`<ul>`，沒有巢狀：

| 網頁上的形式 | 層級 |
|---|---|
| 段落開頭「壹、」「貳、」「叁、」 | 第 1 層 |
| 段落開頭「一、」「二、」 | 第 2 層 |
| `<ol>` 項目 | 第 3 層 |
| `<ul>` 項目（瀏覽器顯示成圓點） | 第 4 層，屬於它前面最近的第 3 層 |
| 同一個第 3 層底下、排在 `<ul>` **後面**的 `<ol>` | 第 5 層，屬於它前面最近的第 4 層 |

第 5 層在瀏覽器上看起來和第 3 層一樣（都是 1. 2.），要從**位置和語意**判斷。例如「b. 在以撒身上我們看見…乃是領受—…：」以冒號結尾，下面接的 `<ol>` 就是它的子項，不是新的第 3 層。

### 坑 2：編輯者手打的編號

有些第 3 層項目不在 `<ol>` 裡，而是段落文字直接寫「2. 雅各的歷史…」「3. 神藉着…」，前面可能還有空白。把它們當成第 3 層，並**接續**前面 `<ol>` 的編號。

### 坑 3：編號規則

綱要五層的編號由上而下是：

1. 壹、貳、叁…
2. 一、二、三…
3. 1. 2. 3.
4. a. b. c.
5. (一) (二) (三)…（**中文數字**，不是 (1)）

每一層都要在 .md 裡寫出編號，不能只靠縮排。

### 坑 4：經節誤判

「晨興餧養」底下先列經節，再接一段信息。經節的開頭是**書卷簡稱＋數字**（出三15、創三一40～41、帖前一1），後面接『…』。

- 內文段落也可能有『』。例如「保羅在加拉太六章十六節的末了說，『就是臨到神的以色列。』…」是信息，不是經節。
- 每天的經節數量不一定，可能只有 1 處。

### 坑 5：標頭的標點被改

`<h2>` 是「特會名稱『總題』」寫在同一行。拆成兩行沒關係，但**『』要保留**。篇題「第一週、認識並經歷…」的「、」也要保留，不要換成空格。原則：除了下面「允許的改動」以外，不要動任何一個標點。

### 坑 6：雜訊字元

正文裡夾著零寬空白（U+200B）和 `&nbsp;`，要去掉。HTML 實體要轉回原字：`&mdash;`→—、`&hellip;`→…、`&bull;`→•。

### 坑 7：異體字

網頁用的是「爲、着、裏、彀、餧、卽」等字形，**照抄**，不要轉成「為、著、裡」。網頁本身也混用（同一句可能出現「成爲」和「成為」），一樣照原樣。

### 坑 8：Markdown 把編號吃掉

`- 1. 文字` 會被 Markdown 解析成巢狀的有序列表，渲染時編號會跑掉。第 3 層的編號要跳脫成 `1\.`。

---

## 允許的改動（只有這些）

- 新增「**總題**」標記，以及「綱要」「晨興聖言」兩個 `##` 標題。
- 「【週 一】」改成 `### 週一`；「第一週•週一」改成 `### 週一`（放在「晨興聖言」底下）。
- 第 3～5 層補上編號，用縮排表示層級。
- 經節改成引用區塊，出處加粗。
- 段落結尾的「--參讀：…」拆成獨立一行斜體。

## 輸出格式

```markdown
# 二○二六年、九月秋季國際長老及負責弟兄訓練

**總題**：『亞伯拉罕、以撒、雅各的神』

## 第一週、認識並經歷亞伯拉罕的神、以撒的神和雅各的神，而成爲神的以色列

**讀經**：創二八13，三三20，出三6、14～15，徒三13，加六16，帖前一1

## 綱要

### 週一

**壹、我們的神乃是三個特別人物—亞伯拉罕、以撒、雅各—的神；…：**

- 一、亞伯拉罕、以撒、雅各是以色列國的根基；…：
  - 1\. 神的子民所以能成爲神的子民，…
  - 2\. 我們都需要有亞伯拉罕、以撒、雅各的成分；…

### 週三

- 二、以撒是子最佳的表徵；…：
  - 2\. 以撒的原則乃是領受的原則—二五5，林前四7：
    - a. 子神的意義是一切都是領受，…
    - b. 在以撒身上我們看見，…乃是領受—…：
      - (一) 以撒與亞伯拉罕的關係是領受的關係；…
      - (二) 神是父，一切都從祂而出；…

## 晨興聖言

### 週一

#### 晨興餧養

> **出三15** 『神又對摩西說，…』

> **太二二32** 『「我是亞伯拉罕的神，…」…』

聖經給我們看見，神的子民有兩個起點：…（倪柝聲文集第二輯第十五册，二至三頁。）

#### 信息選讀

亞伯拉罕、以撒、雅各有他們在神面前特別的地位，…

…（創世記生命讀經，九八四至九八五、九八八頁。）

*參讀：亞伯拉罕以撒雅各的神，第一章；創世記生命讀經，第六十二篇。*
```

排版細節：
- 第 1 層用加粗段落，第 2 層起用列表；每層縮排 2 格。
- 某一天的綱要如果從第 2 層開始（例如週二直接接「二、」），就直接從列表開始，不要補第 1 層。
- 列表項目之間不空行；列表和段落、標題之間空一行。
- 每段信息之間空一行，不要合併段落，也不要拆段。
